# Shaxmat qirolligi

5–7 yoshli bolalar uchun shaxmat o'quv dasturi: 24 dars, interaktiv varaqalar, 32 ta masala, kompyuterga qarshi o'yin.
Topshiriqlarni o'zbekcha ovoz o'qib beradi.

Telefonda havolani oching va «Bosh ekranga qo'shish» ni tanlang. Shundan keyin dastur internetsiz ishlaydi.

Bu repoda faqat tayyor (yig'ilgan) fayllar turadi.
